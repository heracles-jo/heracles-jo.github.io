## 기능

- 다크 테마
- UI 다국어 지원
- 홈 페이지 고정 게시물
- 계층형 카테고리
- 인기 태그
- 목차
- 최종 수정 일자
- 구문 강조
- 수식 표현
- Mermaid 다이어그램 & 플로우차트
- 다크 모드 이미지
- 미디어 임베드
- 댓글 시스템
- 내장 검색
- Atom 피드
- PWA
- 웹 분석
- SEO 및 성능 최적화

## 기여하기

_풀 리퀘스트_, _이슈_, _토론_ 등의 기여가 오픈소스 커뮤니티를 배우고, 영감을 주고, 창조하는 놀라운 공간으로 만든다. 어떤 기여든 진심으로 감사히 여긴다.
자세한 내용은 "[기여 가이드라인][contribute-guide]"을 참고한다.

### 서드파티 자산

이 프로젝트는 [Jekyll][jekyllrb] 생태계와 [여러 훌륭한 라이브러리][lib]를 기반으로 하며, 비상업적 오픈소스 소프트웨어 라이선스 하에 [VS Code][vscode]와 [JetBrains][jetbrains]가 제공하는 도구를 사용하여 개발되었다.

프로젝트 웹사이트의 아바타와 파비콘은 [ClipartMAX][clipartmax]에서 가져왔다.
